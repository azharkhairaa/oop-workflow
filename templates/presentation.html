Sistem OOP Workflow

Helpdesk Workflow berbasis Flask + Google Sheets

Menyajikan ringkasan arsitektur, pilar OOP, design pattern, modularitas, dan contoh skenario penggunaan pada aplikasi pengelolaan aduan.

Pembukaan dan Tentang Aplikasi

Aplikasi ini mengelola aduan pelanggan secara end-to-end: mulai dari pembuatan tiket, penugasan admin sesuai divisi, hingga pencatatan riwayat pesan. Data disimpan di Google Sheets sehingga ringan untuk prototipe kelas dan mudah dipresentasikan.

Fokus utama: alur aduan yang jelas, pembagian peran (Client/Admin), dan pencatatan log yang transparan.

Penerapan Pilar OOP

Encapsulation

Data tiket disembunyikan melalui atribut privat dan diakses via getter/setter.

class BaseTicket: def __init__(...): self._status = "Aduan Masuk" def get_status(self): return self._status def set_status(self, new_status): self._status = str(new_status)

Abstraction

BaseTicket menyediakan kontrak umum `get_kategori()` tanpa detail implementasi.

class BaseTicket: def get_kategori(self): pass

Inheritance

Setiap kategori tiket mewarisi BaseTicket untuk berbagi struktur data.

class TechTicket(BaseTicket): def get_kategori(self): return "Technical Support"

Polymorphism

Method `get_kategori()` di-override di tiap child class tetapi dipakai dengan cara yang sama.

ticket = TicketFactory.create(kategori, ...) kategori = ticket.get_kategori()

Penggunaan Design Pattern

Factory Pattern

Menghasilkan objek tiket sesuai kategori tanpa membeberkan kelas konkret.

class TicketFactory: @staticmethod def create(kategori, user_id, uraian, dokumen=""): if kategori == "Billing": return BillingTicket(...)

State-like Transition

State-like Transition: `WorkflowEngine.process_action()` memusatkan transisi status dan pencatatan log agar konsisten.

if action_type == "DISPOSISI": new_status = "Disposisi" elif action_type == "SELESAI": new_status = "Aduan selesai"

Implementasi Modularitas

Setiap modul memiliki peran yang jelas, sehingga perubahan dapat dilakukan tanpa merusak bagian lain.

app.py – kontrol alur, session, dan routing
models.py – definisi entitas domain
workflow.py – logika transisi status
database.py – akses data Google Sheets
